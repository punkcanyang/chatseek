# Chatseek 1.5.0（2026-10-08）

侧栏搜到一段对话之后，可以在扩展自己的分页里把本机已经收录的内容读完。仍然只读，不发网络请求，不碰四家网站的 DOM，不碰 Gemini 的 `batchexecute`。权限仍只有 `sidePanel`。IndexedDB 仍是版本 3，没有新表，也没有新索引。

## 阅读页

- 每一行有「阅读」。点它，或点标题下面的预览，用 `chrome.tabs.create` 打开 `reader/index.html`（不需要 `tabs` 权限）。点标题仍回到原来的网站。
- 阅读页只读 IndexedDB：标题、平台、日期（仍是「约」「早于」「日期未知」那套）、已收录的全部消息。用户和助手分开标。
- 从搜索结果进来时，地址里带着查询。第一处命中滚进画面并黄底高亮；页顶「上一处」「下一处」在两端停住，不绕回。高亮用文本节点和 `<mark>`，英文整词、中文按字，和侧栏同一套规则。
- 「去原网站打开」使用收录时存下的网址，不重新拼。Gemini 的 `/u/数字/` 还在。
- 只有标题、没有消息时，页上写「仅有标题，未收录消息」，并仍可去原网站，不是空白页。
- 已封存的对话照样能读。页顶灰色标签沿用 1.4.0 的文案：繁体「已封存」，简体「已归档」。
- 聊天正文只当纯文本。换行保留，三个反引号围起来的代码块用等宽字。不解析 HTML，不执行脚本，不加载正文里的图片地址。
- 上千条消息只把视口附近的一段放进 DOM，其余留在内存里。
- 对话已经从索引移除时，阅读页说明它不在本机索引里。不会把 `removed:<id>` 记号清掉，也不会把对话加回来。
- 阅读页跟随侧栏的语言选择（`localStorage` 键 `chatseek.uiLocale`）。九种语言的新文案都在 `_locales/`。

## 消息顺序

收录时把当时页面上的消息 id 顺序记在对话的 `messageOrder` 字段上（普通字段，不升数据库版本）。之后再滚出更早的消息，会按重叠的 id 嵌进这条顺序。1.5.0 之前的旧记录没有这个字段，阅读页先按收录时间排；再次打开原对话并收录到消息后，会写成页面顺序。

## 侧栏排序

列表可以按最后对话时间（默认，新的在前）、标题、收录时间或消息数排序，每种都能反过来。最后对话时间里，确切时间在前，然后是「约」，再是「早于」，「日期未知」始终在最后；正序反序只改变每一档内部的顺序。正在搜索时默认改成相关度，清空搜索后回到原先保存的排序。选择记在侧栏自己的 `localStorage`（`chatseek.listSort`），活跃、平台、已封存、全部共用。不读消息正文。

## 侧栏移除按钮

每一行右上角是一个圆形叉，代替原来的「从索引移除」文字按钮。平常比较淡；鼠标停在这一行，或键盘聚焦到这个按钮（或这一行里）时变清楚，并有焦点环。悬停提示和 `aria-label` 仍用原来的 `remove` 文案，九种语言都是。点下去还是先弹出确认，确认之后才从本机索引删除。

## 没有改的

- 不发网络请求，不拦截 fetch / XHR，不读 API Key，不碰 `batchexecute`。
- 内容脚本不改。阅读页不写索引。
- 扩展页面的 CSP 增加 `img-src 'self' data:`，阅读页不能加载外部图片或脚本。
