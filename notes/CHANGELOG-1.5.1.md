# Chatseek 1.5.1（2026-10-08）

阅读页把已经收录的 Markdown 排成标题、粗斜体、清单、引用、代码、表格和链接。侧栏预览仍是纯文字，但不再露出 `**`、`#`、`` ``` `` 这些记号。同一段对话如果已经开着，再点一次会切回那个分页，而不是再开一个。侧栏的「阅读」和「去原网站打开」改成小图标。权限仍只有 `sidePanel`。不发网络请求，不改内容脚本，IndexedDB 仍是版本 3。

## 阅读页

- 你写的和对方回的用同一套排版。
- 标题、`**粗体**`、`*斜体*`、有序和无序清单（含嵌套）、引用、行内码、三个反引号的代码块、GFM 表格、链接、分隔线会排出来。
- 代码块用等宽字，过长时横向滚动，右上角有「复制」。点一下把代码放进剪贴板，不需要新权限。
- 表格在窄宽度里横向滚动。
- 链接同时显示文字和网址。只有 `http` / `https` 能点，并且在新分页打开（`target=_blank`，`rel=noopener noreferrer`）。`javascript:`、`data:`、`file:`、`chrome-extension:`、相对地址和 `//` 开头的地址只是文字。
- 图片不变成 `<img>`，显示成「[图片: 说明] 网址」这种文字（随界面语言）。扩展页面的 CSP 仍禁止外部图片。
- 消息里的 `<script>`、`<img onerror>` 和其他 HTML 标签一律当文字，不执行。没有用 `innerHTML` 塞正文。
- 搜索仍按收录下来的原文做字面匹配（英文整词、中文按字）。黄底可以落在粗体、行内码、代码块和表格里；一个命中若跨过 `**` 的边界，看得见的那几段都会亮。上一处／下一处仍在两端停住。代码块里的命中会横向滚进画面。
- 长对话仍只把视口附近的一段放进 DOM（最多 60 条）。解析按条缓存，滚出画面的消息不会先全部解析。

排版写在扩展自己的 `src/markdown.js` 和 `src/markdown-dom.js`（约 39KB 源码），跟项目同一份 MIT 许可，没有第三方运行库，也没有 CDN。

## 侧栏预览

- 显示时去掉标题记号、粗斜体记号、清单符号、代码围栏和反引号、引用的 `>`、表格竖线。链接只留文字，不留网址。
- 旧的摘录不改数据库，打开侧栏时再去掉记号。
- 黄底仍标在去掉记号之后的文字上。

## 同一个分页

- 点侧栏标题、点「去原网站打开」、或在阅读页再点「去原网站打开」：内容脚本已经报过这个对话时，切到那个分页并把它的窗口带到前面。网址的 `?`、`#` 不算不同对话；Gemini 的 `/u/数字/` 也不算。
- 点「阅读」：阅读页已经开着这个对话时，切回那个分页。比对的是对话 id，搜索词不同也算同一个。
- 分页已经关掉，或内容脚本还没报过这个页面，就照旧新开一个，不会卡住。
- 没有加 `tabs` 权限。原网站靠内容脚本上报的分页编号；阅读页靠 `chrome.runtime.getContexts` 看扩展自己的分页。

## 图标按钮

- 侧栏每一列的「阅读」是书本图标，「去原网站打开」是外连箭头。平常和右上角的圆形叉一样淡，鼠标停在这一列或键盘焦点进到这一列时才变清楚。
- 阅读页页顶的「去原网站打开」是同一款外连箭头，一直看得见，滑过或聚焦时有圆底和焦点环。
- 名字在 `aria-label` 和悬停提示里，九种语言都还是原来的文字。图标是内嵌 SVG，没有外链字型。
- 按钮可以用 Tab 聚焦，Enter 或空白键触发，焦点环看得见。320px 宽的侧栏里，图标不压标题、日期、预览和绿框。

## 没有改的

- 不发网络请求，不拦截 fetch / XHR，不读 API Key，不碰 `batchexecute`。
- 内容脚本不改。阅读页不写索引。
- 权限仍是 `["sidePanel"]`。CSP 仍不允许外部图片和远程脚本。
