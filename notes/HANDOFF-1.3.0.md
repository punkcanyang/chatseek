# Chatseek 1.3.0 交接

侧栏三件事：标题下的预览、当前对话的绿框、简体「条消息」。版本 1.3.0。没有新权限，没有网络请求。示例截图（假数据，不是你的聊天）在 `docs/panel-1.3.0-idle.png` 和 `docs/panel-1.3.0-search.png`。

## 预览为什么用第一条提问

没在搜索时，标题下面显示**你发出的第一条提问**，不是最后一条消息。

最后一条多半是助手的长回复，两行截断后往往只剩「好的，下面是……」，和标题放在一起也认不出是哪段。第一条提问的开头就是你当时打进去的那句话，两行刚好能看到。库里没有用户提问、只有回复时，才改显示最后一条。鼠标停上去会多展开几行，不是把整段对话展开。

搜索时不显示这句开头，改显示命中词附近的一小段，命中的词用黄底标出。聊天里如果出现 `<script>` 或 `<img>` 这种字，会当文字显示，不会变成页面元素。只有标题、正文还没收录的行，会写「仅有标题，未收录消息」（繁体「僅有標題，未收錄訊息」），不要把它当成预览正文。

打开侧栏看列表时，用的是记在对话上的节选，不会把消息表整表读出来。很老的索引第一次打开时，每条最多翻 40 条消息来补这句节选；把那段对话再打开一次，就会改成页面上真正的第一条提问。

## 绿框

你正看着的那段对话，侧栏里那一行有一圈绿色边框（`#3DDC97`）。换一个标签、在 ChatGPT / Claude / Grok / Gemini 页面里点进另一段、或者新开一段，框会跟着走。那一行如果在侧栏外面，会自己滚进来一次。你接着自己滚动时，它不会反复把列表拽回去。

对得上，是因为网址会换成和入库时一样的对话 id。Gemini 带 `/u/1/`、`/u/4/` 都认，同一个对话 id 是同一行。分享页、`/app/download` 这种没有对话 id 的页不会亮。

没有加 `tabs` 权限。这几个网站本来就在扩展的网站权限里，侧栏本来就能用 `chrome.tabs` 看到这些标签的网址（点结果打开原对话，用的就是这个）。内容脚本在网址变了、或者这个标签重新变成当前页时，会再告诉侧栏一次「现在的网址」。报的只有网址，没有聊天正文。不改页面的 `history`，也不拦请求。

列表最多 80 条，筛选或搜索把这行滤掉时，绿框先不出现；清掉搜索、这行回到列表里，框还在。

## 简体量词

简体底部和健康提示现在是「N 条对话 · M 条消息」「最后收录 …，N 条消息」。以前健康提示写成了「则消息」，和底部的「条消息」不一致。繁体仍是「則訊息」，没有改成简体的「条」。

## 请你在自己的 Chrome 里看

1. `chrome://extensions` 里重新加载 Chatseek，确认版本是 **1.3.0**。已经开着的 ChatGPT、Claude、Grok、Gemini 标签各刷新一次。
2. 打开侧栏，先不要输入。每一行标题下面应有一两行字，是你当时的第一句提问，不是助手最后那句「好的」。把鼠标停在某一行上，预览会多出几行，整段对话不会展开。
3. 找一条只在网站侧栏里出现、你还没点进正文的对话。它应该写着「仅有标题，未收录消息」（繁体界面是「僅有標題，未收錄訊息」），而不是一段聊天正文。
4. 点进一条已经收录正文的对话。侧栏里同一行出现绿色边框。再点网站侧栏里的另一条，绿框应跟着换过去，不必关 Chatseek。如果那一行在侧栏很下面，它应自己滚进视野；你再用滚轮往上翻，列表应留在你翻到的地方，不要被拽回去。
5. 换到另一个聊天网站的标签，绿框改到那个网站的对话上。换到一个普通网页（比如邮箱），绿框应消失。
6. 新开一段对话，发出一句很少见的话。等它出现在 Chatseek 列表里，绿框应在这行上，预览里能看到你刚发的那句。
7. Gemini 如果用的是带 `/u/数字/` 的网址：点开一段已经收录的对话，绿框应落在同一条上，不要因为 `/u/1/` 和 `/u/4/` 对不上而亮错行。分享页不要亮。
8. 在侧栏搜一个你记得出现在正文中间、不在标题里的词。预览应变成这个词附近的一小段，这个词是黄底。再搜一个显然不存在的词，应是「没有匹配的对话」。
9. 把浏览器语言改成简体中文时，底部是「条消息」，健康提示也是「条消息」，不要再出现「则消息」。改成繁体中文时，是「則訊息」，不要出现「条消息」。英文是 messages。

## 自动化

```bash
npm run verify
npm run test:search
npm run test:fixture
npm run test:gemini
```

`test:search` 里的 `scripts/preview-test.mjs` 覆盖：第一条提问优先、命中片段和高亮不会把聊天文字当成 HTML、仅有标题、网址对上侧栏行（含 Gemini `/u/N/`）、简体「条消息」和繁体「則訊息」。

示例截图用 `node scripts/screenshot-panel.mjs` 重做。它用本机 Chrome 打开侧栏页面，写入假索引，不登录任何网站。
