# Chatseek 1.2.1（2026-10-08）

只改侧栏日期的显示。四家平台共用 `src/activity-time.js`。排序、置信度、收录方式都不变。仍然只读页面，不发网络请求。

## 日期显示

- 自己没有精确时间、又排在一条精确时间（`page-exact`）或刚观察到的活动（`observed`）下面的行，不再显示「約 3 小時前」／「约 3 小时前」。那种「每往下一行减一小时」只用于排序，不是真实活动时间。
- 这些行改为「早於 YYYY-MM-DD HH:mm」（简体「早于 …」，英文 `before …`）。时间是同一侧栏里、它上方最近一条精确或观察时间的绝对日期，本地时区，和原来悬停用的绝对格式一样。过几天再打开，这句话不变。
- 上方没有这种锚点的行（包括整栏都没有，以及排在第一条精确时间上面的行）仍是「日期未知（收錄於 …）」／「日期未知（收录于 …）」。没有改成「晚于」：下方那个锚点只能说明它更新，不能给出一个不会被误读成活动时间的上界。
- 分组时间（Today / Yesterday / Previous 7 Days，`page-bucket`）仍显示「約」／「约」。分组时间是区间里的一个点，拿来写「早于那个点」可能是错的，所以不算「早于」的锚点。它仍然参加排序插值，也仍然不会盖掉已经拿到的精确时间。
- 精确时间和观察到的新消息显示方式不变，前面不加「早於」或「約」。
- 1.2.0 已经写进 IndexedDB、当时没有存锚点时间的估计行，在该站侧栏再扫一次之前显示「日期未知（收錄於 …）」。打开旧库不会改写排序用的时间，也不会丢对话。刷新网站标签页扫过侧栏之后，才变成「早於 …」。

## 没有改的

- 来源优先级不变：`page-exact` 和 `observed` 高于 `page-bucket`，高于 `sidebar-rank`，高于 `first-seen`。低的不会盖掉高的。
- 侧栏从上到下的排序不变。
- 不新增 IndexedDB 版本。锚点时间是对话记录上的 `olderThanAt` 字段。
