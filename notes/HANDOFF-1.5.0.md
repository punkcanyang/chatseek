# Chatseek 1.5.0 交接

本机阅读页。版本 **1.5.0**。没有新增权限，没有网络请求，数据库仍是版本 3。侧栏选的语言还是记在扩展页面自己的 `localStorage`（键 `chatseek.uiLocale`），阅读页读同一份。

示例截图（假数据，不是你的聊天）在：

- `docs/reader-1.5.0-hit.png`：从搜索打开，命中是黄底，页顶有上一处／下一处和计数。
- `docs/reader-1.5.0-title-only.png`：只有标题，写着「仅有标题，未收录消息」。
- `docs/reader-1.5.0-archived.png`：已封存的对话仍可阅读，页顶是灰色标签。简体界面写「已归档」，繁体写「已封存」，跟 1.4.0 一样。
- `docs/panel-1.5.0-read.png`：侧栏每一行的「阅读」。
- `docs/panel-1.5.0-remove-x.png`：窄侧栏里，一行悬停、一行键盘聚焦时的圆形叉，旁边是当前对话的绿框。长标题没有被叉盖住。
- `docs/panel-1.5.0-sort-menu.png`：排序菜单打开，默认是「最後對話時間」。
- `docs/panel-1.5.0-sort-relevance.png`：搜索时排序变成「相關度」。

截图用的是简体。Claude 那条「封存的读书笔记」仍是写进示例索引的，实机上 Claude 不会自己变成已封存。

## 请你在自己的 Chrome 里看

1. 打开 `chrome://extensions`，重新加载 Chatseek，确认版本是 **1.5.0**。已经开着的 ChatGPT、Claude、Grok、Gemini 分页各刷新一次。不要清空本地索引。权限说明里不应出现新项目。
2. 打开侧栏。每一行标题旁边应有「阅读」（英文界面是 Read）。点「阅读」或点标题下的预览，应新开一个分页，页面是 Chatseek 自己的，不是 ChatGPT 网站。排序默认是「最后对话时间」、新的在前。改成标题或消息数，并切换方向。换到已封存或全部，再关掉侧栏重新打开，选择应还在。
3. 这个分页里能看到标题、是哪一家、日期，以及已经收录的消息。你写的和对方回的要能分开。消息里如果有网址或 `<img>` 这类字，只是文字，不要变成图片，也不要弹出窗口。
4. 回到侧栏，搜一个你记得的词。排序应改成「相关度」。清空搜索后，回到第 2 步保存的那种排序。再点「阅读」。阅读页应跳到第一处黄底，页顶能看到「上一处」「下一处」和类似 `1 / 3` 的计数。到第一处时「上一处」停住，到最后一处时「下一处」停住。
5. 点「去原网站打开」。应打开原来的那段聊天。如果是 Gemini，网址里的 `/u/数字/` 应还在。
6. 找一条标着「仅有标题，未收录消息」的对话，点「阅读」。页上应有这句话和「去原网站打开」，不要是一片空白。
7. 打开一条已封存的对话的阅读页。页顶应有灰色标签（简体「已归档」，繁体「已封存」），消息仍在。再找一条对话，点该行右上角的圆形叉（悬停或键盘聚焦时比较清楚；提示仍是「从索引移除」）并确认。如果还留着它的阅读页，刷新后应写这段已经不在本机索引里。回到侧栏，不要点开网站上的那一段，它不应自己出现。
8. 侧栏右上角把语言改成 English 或繁體中文，再开一次阅读页。按钮和「仅有标题」应跟着变。改回「跟随浏览器」后，阅读页也跟着浏览器语言。

## 自动化

```bash
npm run verify
npm run test:search
npm run test:fixture
npm run test:gemini
npm run test:upgrade
```

`scripts/reader-test.mjs`（含在 `test:search` 里）：纯文本和代码块、`<img onerror>` / `<script>` 不会变成元素、外部图片地址不会变成 `src`、命中上一处／下一处到头停住、英文整词和中文、仅标题、封存标签、Gemini `/u/N/`、移除后的记号不会被阅读页清掉、3000 条只渲染视口附近的节点。

示例截图用 `node scripts/screenshot-reader.mjs` 重做。它用本机 Chrome 打开扩展页面，写入假索引，不登录任何网站。
