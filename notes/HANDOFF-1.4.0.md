# Chatseek 1.4.0 交接

三件事：封存仍可搜、页签顺序、九种语言加手动切换。版本 **1.4.0**。没有新增权限：侧栏选的语言记在侧栏页面自己的 `localStorage`。没有网络请求。

截图里 Claude 那条「封存的读书笔记」是写进示例索引的，用来让「已封存」页有第二家。Claude **没有**封存检测，实机上不会自己变成已封存。

## 封存在实机上怎么发生

只有 **ChatGPT** 会标。两种页面，都要页面上写明了：

- 设置里的已封存聊天列表（对话框或区域标题像 “Archived chats” / 「已封存的聊天」）。列表里的对话标成已封存。
- 打开一段已封存对话后，页面上有封存横幅，或有一颗文字正好是 Unarchive / 取消封存 的按钮（不在菜单里、也不在消息正文里）。

Claude、Grok、Gemini 没有这种明确标记，所以**一律不标**。某段从侧栏消失，索引里的状态不动，也不会被删掉。

ChatGPT 网站侧栏的对话列表里又出现这段，或打开的对话页上有输入框、没有上面两种标记，灰标签会去掉，回到活跃。消息里贴的 `/c/` 链接、认不出的对话框、或页面还没出现输入框时，都不改状态。

## 从索引移除

每一行的「从索引移除」会先弹出确认。确认后只删这台浏览器里的这一条：对话、消息、用来搜索的词条。网站上的聊天还在，Chatseek 也不会去点网站的删除。

删掉后，网站侧栏里还列着它，刷新也不会被加回来。在网站上再打开同一段对话，会按当时页面重新收进来。这是预期行为，不是删不干净。

## 请你在自己的 Chrome 里看

1. `chrome://extensions` 里重新加载 Chatseek，确认版本是 **1.4.0**。名称应跟着浏览器语言（例如浏览器是英文时，说明是英文）。已经开着的 ChatGPT、Claude、Grok、Gemini 标签各刷新一次。本地旧索引应还在，不要被清空。
2. 打开侧栏，先不要输入。最左边、且处于选中的页签应是「活跃中」（浏览器是简体时是「活跃中」，繁体是「活躍中」，英文是 Active）。顺序是：活跃中 → ChatGPT → Claude → Grok → Gemini → 已封存 → 全部。全部在最后。
3. 点 ChatGPT。列表里只剩未封存的 ChatGPT。在搜索框打一个只出现在 Claude 对话里的词，应是「没有匹配的对话」。回到「活跃中」再搜，应能搜到。点「全部」时，已封存的也能被搜到。
4. 在 ChatGPT 把一段已经收录的对话封存（从设置打开已封存列表，或打开那段对话直到页面写出已封存／出现取消封存）。回到侧栏：「活跃中」和 ChatGPT 页签里它消失；「已封存」里还在，旁边是灰色「已封存」；搜它的标题，在「已封存」和「全部」里能中，在「活跃中」里不中。
5. 把这段取消封存，或让它重新出现在 ChatGPT 普通侧栏里。刷新后灰标签应消失，它回到「活跃中」。
6. 在 Claude、Grok 或 Gemini 上，把一段对话从网站侧栏里弄没（如果该网站做得到），不要点 Chatseek 的移除。Chatseek 里它应仍在「活跃中」，不要变成已封存，也不要自己消失。
7. 任选一行（最好是网站侧栏里看得到的那种）点「从索引移除」。先出现确认，写明网站上的对话不会删。点取消，这一行还在。再点一次并确认，这一行从侧栏消失。刷新网站分页、不要点开它，Chatseek 里它应仍然不在。再到网站上把这一段打开，等几秒，它应重新出现在索引里，预览也回来；如果它正是当前分页，绿框也回来。
8. 右上角语言默认是「跟随浏览器」（英文界面写 Browser language）。改成 English，页签、底部计数、提示应变英文，日期不再是中文的「小时前」。改成日本語，应出现「アクティブ」「アーカイブ」「インデックスから外す」。关掉侧栏再打开，选择还在。如果另一个窗口也开着侧栏，那边也跟着换。改回「跟随浏览器」后，又跟着浏览器语言。`chrome://extensions` 里 Chatseek 的权限说明不应出现新项目。
9. 找一条显示「早于……」或「约……」或「日期未知」的对话（没有确切时间的那种）。换到英文应变成 before / ~ / Unknown date，日文应变成「より前」等，日期的月日写法跟着该语言，而不是所有语言都印成同一种 `2026-10-08 13:19`。
10. 顺手看一眼 1.3.0 还在：标题下有预览；搜索时命中的词是黄底；正在看的那一行有绿色边框；底部健康提示还在；简体是「条消息」，繁体是「則訊息」，不要出现「则消息」。

## 自动化

```bash
npm run verify
npm run test:search
npm run test:fixture
npm run test:gemini
npm run test:upgrade
```

`scripts/archive-test.mjs`：ChatGPT 横幅和封存列表会标、消息正文和菜单里的 Unarchive 不会标、别的对话框里的 Unarchive 不会标、消息里的「Archived chats」标题不算封存列表、侧栏优先于封存列表、Claude / Grok / Gemini 一律 `supported: false`；未封存再看到会恢复，但消息里的 `/c/` 链接、认不出语言的封存对话框、没有输入框的对话页都不会恢复；页签过滤；搜索限制在当前页签；移除后消息和倒排都没了，侧栏和封存列表重扫不会加回来，打开对话有消息时才再收录。

`scripts/upgrade-1.4-test.mjs`：用 1.3.0 的数据库版本 2 造一条带预览、消息和倒排的记录，升到版本 3 后内容还在，且不会被标成已封存。

`scripts/i18n-test.mjs`：九种语言的 key 一致，`_locales/*/messages.json` 和 `src/i18n.js` 一致，面板没有写死的中文界面句子，`Intl` 日期按语言不同。

示例截图用 `node scripts/screenshot-panel.mjs` 重做。它用本机 Chrome 打开侧栏页面，写入假索引，不登录任何网站。
