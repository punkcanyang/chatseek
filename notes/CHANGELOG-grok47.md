# Chatseek 1.0.1（Grok 4.7，2026-09-23）

只修收聊天、索引、搜索、日期和侧栏小问题。没有新站点，没有改架构，没有做 Claude 实机。

## 修了什么

- 采集失败会重试。以前一失败就把指纹记下，这条聊天直到页面再变才会再写。现在服务端确认成功才记指纹；消息还没渲染出来时不锁死。同一页的采集排队，避免旧快照覆盖新消息。
- IndexedDB 连接被关掉之后会重开。侧栏不再把「库连接断了」显示成索引没了。扩展 Reload 不清库。
- 搜索改成整词。`star` 不再命中 `starship`，`plan` 不再命中 `planning`。大小写不敏感。多个词必须出现在同一条对话里。
- 日期：精确时间（行内 time / 页面 JSON）优先于 Today、Previous 7 Days 这种分组。分组标题能盖住长列表，不再只照顾前 12 条。聊天标题本身像月份时，不会被当成日期。
- Grok：没有 role 属性时也会收下消息；套了好几层的容器只留最里面一层。非 UUID 的长 id 也能对上 `/c/`、`/chat/`。
- 侧栏：第一次打开先显示「正在读取」，不要闪成「还没有收录」。中文输入法组字结束再搜。清除失败会报错。切回侧栏会刷新。没有时间戳时显示「无日期」，有时间戳可悬停看绝对时间。
