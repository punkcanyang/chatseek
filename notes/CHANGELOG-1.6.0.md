# Chatseek 1.6.0（2026-10-08）

閱讀頁可以留下你已經打開過的對話裡、頁面上已經載好的圖。縮圖存在這台電腦的 IndexedDB。權限仍只有 `sidePanel`。不新增 `unlimitedStorage`，`host_permissions` 不擴大。不發新的網路請求，CSP 不改。資料庫升到版本 4，舊索引會跟著升級。

## 什麼時候會存

- 只在你打開那段對話、圖片已經畫在頁面上時才存（`complete` 且有實際像素）。不預先抓，不在背景掃別的分頁。
- 內容腳本把那張已經載入的 `<img>` 畫到 canvas，長邊縮到 512，存成 WebP；這個 Chrome 不支援 WebP 時改存 JPEG。
- 每張大約 150KB 以內。超過就降低畫質。降到底還是超過，這張不存。
- 存的是縮圖、提示詞、alt，以及它屬於哪一則訊息、第幾張。不存圖片網址，因為簽名網址會過期。
- 存圖是一段一段做的，不會卡住頁面，也不會拖慢 3000 則訊息的收錄和閱讀頁捲動。

## 存不了的圖

跨網域、canvas 被污染，或轉檔時丟出 `SecurityError`：仍記下提示詞和 alt，標記為未快取。閱讀頁在原來的位置顯示「圖片未快取（原網站限制）」，並附上回到原網站的按鈕。這句話有九種語言。

不會為了能畫進 canvas 而重新載入圖片，也不會改 `crossOrigin`。

## 閱讀頁

- 縮圖用 `data:` 網址顯示，所以不用放寬 CSP。
- 點縮圖或佔位上的「前往原網站開啟」，跟頁頂的外連箭頭同一套：那段對話已經開著就切回去，不會再開一個分頁。
- 閱讀頁只讀目前畫面上那一段訊息的圖，不會一次把整段很長的對話裡每張圖都讀進記憶體。

## 側欄

- 底部顯示圖片快取佔了多少空間。
- 「清除圖片快取」會先問一次。清掉的是縮圖，對話和訊息還在。
- 從索引移除一段對話時，它的圖一起刪。

## 沒有改的

- 不攔截 fetch / XHR，不讀 API Key，不碰 `batchexecute`。
- 不碰 Claude 的 artifact iframe。
- 頭像、icon、介面上的小圖不收。
