# Chatseek 1.5.1 交接

阅读页把 Markdown 排成能读的样子。同一段对话已经开着时会切回去，不再每次都新开分页。侧栏的「阅读」和「去原网站打开」改成小图标。版本 **1.5.1**。没有新增权限，没有网络请求，数据库仍是版本 3。

排版是扩展里自己的解析器（`src/markdown.js`、`src/markdown-dom.js`，大约 39KB 源码），和项目同一份 MIT 许可。没有从网上加载库。正文只用 DOM 节点和 `textContent`，不用 `innerHTML`。

## 请你在自己的 Chrome 里看

1. 打开 `chrome://extensions`，重新加载 Chatseek，确认版本是 **1.5.1**。已经开着的 ChatGPT、Claude、Grok、Gemini 分页各刷新一次。不要清空本地索引。权限说明里不应出现新项目。
2. 找一段带标题、清单或粗体的对话，点「阅读」。正文应排成标题和粗体，而不是满屏的 `#` 和 `**`。你写的和对方回的都一样。
3. 代码块应是等宽字，太长可以左右滑，右上角有「复制」。点「复制」后，到别处粘贴，应是代码本身。表格太宽时也可以左右滑。
4. 链接应同时看得到文字和网址。点 http 或 https 的链接，应新开一个分页。若正文里有 `javascript:` 开头的地址，它应只是文字，点不了。
5. 若对话里有图片，页面上应是「[图片: ……]」加上网址，不应出现真正的图片，也不应去请求那个网址。
6. 回到侧栏，搜一个你记得出现在粗体或代码里的词，再点「阅读」。那个词应是黄底；「上一处」「下一处」能在各处之间移动，到头就停。代码块里的命中应滚到看得见的位置。
7. 看侧栏标题下面的预览。它仍是普通文字，但不应再出现 `**`、`#`、三个反引号。以前收进来的旧摘录也一样。
8. 打开一条很长的对话，上下滚动，再从搜索跳到很后面的一处。页面应还能滚，不应一次把几千条都画出来。
9. 同一段对话先点开原网站，再从侧栏点标题或外连箭头，应切回已经开着的那个分页，而不是再开一个。阅读页同样：已经开着就切回去。Gemini 带 `/u/数字/` 和不带的，应算同一段。把那个分页关掉再点，才会新开。
10. 侧栏每一列右边是书本和外连箭头，平常比较淡，鼠标停上去或用 Tab 聚焦后变清楚。悬停提示仍是「阅读」和「去原网站打开」。阅读页页顶也是这个外连箭头。把侧栏拉到大约 320px，图标不应压住标题、日期、预览或绿框。

## 做不到的

- 不是完整的 Markdown：四个空格缩进的代码块、参考式链接 `[文字][id]`、脚注、删除线、任务清单的勾选框、数学公式，都还是普通文字或只排了其中能认识的部分。
- HTML 实体（如 `&lt;`）不会翻译成符号，就按原样显示，这样不会变成标签。
- 代码没有语法高亮。
- 搜索仍对着收录时的原文。字被 `**` 从中间切开时，不会把切开的两半当成一个词。
- 侧栏预览里的链接只留文字，不留网址。图片会留下说明和网址。

## 自动化

```bash
npm run verify
npm run test:search
npm run test:fixture
npm run test:gemini
npm run test:upgrade
```

`scripts/markdown-test.mjs`（含在 `test:search` 里）：各种排版、XSS 和非法链接保持为文字、图片不是元素、命中可以跨过粗体边界并落在代码块和表格里、侧栏去掉记号、3000 条带 Markdown 的对话初次绘制和跳转仍限制 DOM 数量。示例截图用 `node scripts/screenshot-markdown.mjs` 重做。它用本机 Chrome 打开扩展页面，写入假索引，不登录任何网站。
