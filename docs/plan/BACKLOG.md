# Chatseek 待辦與已知限制

更新：2026-10-09（UTC+8）。來源：`notes/HANDOFF-*.md` 的已知限制、`docs/plan/Chatseek-功能现况与下一阶段-2026-10-08.md`。
沒有老闆點頭的項目都不要自己開工。

## 要老闆拍板才做

- **上架 Chrome Web Store**：開發者帳號一次 **US$5**，老闆批准才註冊。前置作業（隱私權政策、1280×800 範例資料截圖、描述、每個 host 權限的用途說明）可以先準備，不花錢。定價未定。
- **加任何權限**（tabs、alarms、scripting、unlimitedStorage、新 host…）：一律停下回報。例如跨源 iframe 裡的對話或圖片要讀，需要加那個 host，由老闆決定。
- **手動封存按鈕**（Claude／Gemini／Grok 沒有網站封存標記）：提過，老闆尚未要。
- **匯入官方匯出檔**：唯一能搜到「沒打開過的舊對話」的路線，四家格式不同、工不小，暫不排。

## 改版應對（持續）

- 網站一改版就可能收不到。流程：老闆貼「複製診斷」→ 補 fixture → 修選擇器 → 發版。
- Claude、Grok 還沒有離線 fixture（ChatGPT、Gemini 有）。拿到去識別化的頁面結構再補。
- Claude、Gemini 實機驗收仍靠老闆在自己的 Chrome。

## 已知限制（目前版本）

收錄
- 沒打開過、也沒出現在網站側欄的舊對話搜不到。長對話只收畫面上已經畫出來的訊息。
- 跨源 iframe 讀不到；備援判斷不出角色的輪次記成 assistant。
- 1.7.0 同步：側欄要開著才跑；一次一家；不捲動、不點網站按鈕；網站側欄沒時間也沒則數時判斷不了「沒有新訊息」；佇列最多 500 條側欄連結；看不準是驗證碼／登入時會停。

時間
- Gemini 頁面沒時間，沒在開著分頁送過新訊息的大多是「日期未知」。
- 上一則用詞改了、id 也換了、頁面又對不到時，可能多存一則（1.6.4）。畫面看不到已存的最後一則時不會標「剛剛」。

圖片
- 跨網域的圖會讓 canvas 被污染，只能顯示「原網站限制」佔位：ChatGPT 生圖、Gemini、Grok 大多如此。不加權限、不重新抓圖下這是上限。
- 不存圖片網址；清除快取後要重新打開對話才會再快取；不讀 Claude artifact iframe。
- 「圖片」頁籤不搜尋圖中文字，順序固定按最後活動時間，已封存對話的圖也列出。

閱讀頁／搜尋
- 不是完整 Markdown：四格縮排程式碼、參考式連結、註腳、刪除線、核取方塊、數學式不處理；程式碼無語法著色。
- 表格儲存格內換行存成空白；內文裸網址不進搜尋索引。搜尋是整詞，不做詞幹。
- 背景超過 1.5 秒沒回應時，那次點擊可能多開一個分頁。

封存
- 只有 ChatGPT 有網站封存標記；1.7.1 前封存偵測對現行 DOM 失效（見 ROADMAP）。

其他
- 還沒上架，只能「載入未封裝項目」。沒有收費。
