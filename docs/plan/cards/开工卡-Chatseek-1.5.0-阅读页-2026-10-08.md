# 开工卡：Chatseek 1.5.0 本机阅读页（老板 2026-10-08 点头）

排期：1.4.0（封存／页签／多国语言）合进 main 之后，从新 main 开。

## 要什么
扩展内一个只读阅读页（扩展自己的页面，新分页打开），不连 ChatGPT/Claude/Grok/Gemini，直接读本机 IndexedDB 已收录内容，让用户搜到后确认是哪段对话。

## 验收
1. 侧栏每列可点「阅读」（或点预览）→ 新分页打开该对话阅读页；显示标题、平台、日期（沿用约／早于／日期未知规则）、收录的全部消息，区分用户／助手。
2. 从搜索结果进入：自动捲到第一个命中处并黄底高亮；页顶可「上一处／下一处」跳命中。
3. 页顶按钮「去原网站打开」（原 URL；Gemini /u/N/ 保留）。
4. 只有标题的对话：显示「仅有标题，未收录消息」+ 去原网站打开，不显示空白页。
5. 已封存对话照样能读，页顶显示「已封存」灰标签。
6. 聊天文字一律当纯文本渲染（不当 HTML、不执行脚本、不载外部图片）；保留换行与代码块等宽显示即可，不做完整 Markdown 也可。
7. 多国语言沿用 1.4.0 `_locales`，阅读页所有文案都要翻。
8. 长对话（上千则）开得动，不卡死（可虚拟列表或分段渲染）。

## 硬规矩
- 不加权限、不加网络请求；verify.mjs 照过。只读，不改原网站。
- Cursor 云端 grok-4.7 high，非 Fast；复审 Opus 5.5，额度不够退 Grok 4.7 high（另开 session）。
- $0。
